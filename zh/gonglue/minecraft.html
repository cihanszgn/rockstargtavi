2026年的 Minecraft

#

Minecraft 让你在无尽的方块世界里收集资源、建造设施。游戏不强制单一目标：你可以击败 Ender Dragon，也可以只盖舒适的房屋、经营农场。这份自由可能让新手无从下手，本指南提供可靠的行动顺序。

从2026年开始，版本号按年份命名，例如 26.3。大型更新 Wilderness Bound 于2026年9月15日推出，对应 Java 26.3 和 Bedrock 26.50，加入斑驳森林生物群系、白杨木、羊毛与混凝土楼梯和台阶、坐垫、稻草床、废弃营地，并改进地图。下一版本26.4正在快照测试中。

提示

主菜单会显示版本号。指南或模组若仍提及1.21等编号，信息可能过时，安装前请核对。

开始前：选 Java 还是 Bedrock？

#

Windows 官方商店通常捆绑出售 Java 与 Bedrock，一次购买即可安装两者。主机和手机只有 Bedrock。区别如下：

Java EditionBedrock Edition
平台Windows, macOS, LinuxWindows, Xbox, PlayStation, Switch, Android, iOS
模组支持丰富的模组与光影资源较有限；主要是 Marketplace 内容和附加包
与朋友联机Java 服务器与自行架设的服务器Bedrock 设备间跨平台联机、Realms
适合人群希望使用模组及自建服务器的 PC 玩家使用手机、主机或混合设备的朋友群体

简要建议：朋友用手机或主机就选 Bedrock；在 PC 上想用模组就选 Java。Java 与 Bedrock 玩家通常不能共用服务器，联机前请先统一版本。

价格（minecraft.wiki 的美元列表）：Bedrock 手机版6.99美元，Xbox 与 PlayStation 版19.99美元，Windows 与 Switch 版29.99美元。当地价格以商店为准。Java 系统要求：64位 Windows 10或更新系统，至少四核处理器（如 Core i3-10100 或 Ryzen 3 3100），支持 Vulkan 1.3 且至少2 GB显存的显卡（如 GTX 950 或 RX 460）。流畅游玩推荐 Core i5-12400 与 RTX 2060 同等级配置。模组会提高需求。

注意

仅从 Minecraft 官网、Microsoft Store 或主机商店购买。破解启动器违法，也会危及账号和电脑。

第一夜：最初15分钟的行动步骤

#

游戏在白天开始。完整昼夜约20分钟现实时间。天黑后会生成僵尸、骷髅、蜘蛛和苦力怕等敌对生物。首要目标是在天黑前搭好简易庇护所。

  1. 1
    收集木材

    徒手敲树，至少收集10–12块原木，再加工成木板。

  2. 2
    制作工作台

    用4块木板合成工作台，再制作木镐、斧头和剑。

  3. 3
    寻找石头与煤

    用木镐挖圆石，至少取8块，用于石镐和熔炉。煤既能作燃料，也能做火把。

  4. 4
    寻找食物

    猎取牛、猪或鸡，用熔炉烹熟生肉。取得绵羊的羊毛后，用3块羊毛和3块木板制作床。

  5. 5
    搭建庇护所

    傍晚在山坡挖一个小房间，用方块封住入口。内部放火把，亮处不会生成怪物。

  6. 6
    度过夜晚

    有床就睡觉跳过黑夜，重生点也会移至床边。没床可在地下挖掘；只要带着火把，地下不受昼夜影响。

提示

一根木棍与一块煤可合成火把。随身带20–30支火把，便于地下辨路并阻止怪物生成。

第一周的任务

#
  • 建造长期住所，旁边放储物箱，开辟小块麦田或胡萝卜田。
  • 寻找铁矿：洞穴和山坡石头里有浅色斑点。熔炼成铁锭，制作铁镐、剑和盔甲。
  • 用3个铁锭做桶。桶能装水、化解熔岩危险，有时能救命。
  • 制作盾牌，减少苦力怕爆炸与箭矢伤害。
  • 记下家和重要地点的坐标，这是避免在洞穴迷路的简便方法。

提示

钻石常见于很深的地下，约 Y -58。坐标可通过 F3 界面或游戏设置查看。下矿时带铁镐与水桶。

注意

不要垂直向脚下挖，下面可能是熔岩或洞穴。像楼梯一样斜着向下挖，并保留返回通路。

成长路线：逐个完成目标

#
阶段目标说明
1. 生存住所、食物、铁制工具最初2–3个游戏日
2. 附魔钻石镐、黑曜石、附魔台黑曜石只能用钻石镐开采
3. NetherNether 传送门、堡垒、烈焰棒穿盔甲并带足食物
4. End 准备末影珍珠与末影之眼合成末影珍珠与烈焰粉
5. 巨龙寻找要塞、开启 End 传送门、Ender Dragon带箭、剑与方块
6. 后期末地城、Elytra、自定大型建筑目标由你决定

Nether 传送门至少需要10块黑曜石，可用水桶与熔岩生成。击败巨龙并非必须，但探索 Nether 能让你更强。新手的首个大目标应是附魔台。

资源与仓储

#
  • 食物：种小麦、胡萝卜和土豆，养牛、羊和鸡；使用合适食物即可繁殖动物。
  • 箱子：矿石、食物、建筑方块和装备分箱存放，并用告示牌标注。
  • 经验（XP）：采矿、冶炼和击杀生物获得经验，用于附魔和修理。
  • 备份：定期复制重要世界，每次版本更新前务必备份。

原则很简单：需要时找不到物品，说明仓储混乱。整理好储物区，效率很容易提高一倍。

工具、盔甲与矿层

#

Minecraft 的材料按等级递进。石镐挖铁，铁镐挖钻石，钻石镐挖黑曜石。下表按此顺序列出镐的耐久度。

石头131无用于挖铁
铁25015第一套实用盔甲和桶
钻石156120黑曜石与附魔台
下界合金203120（另有额外韧性）用 Nether 来源的锭升级钻石装备

矿石集中在不同高度（Y 坐标）。钻石生成于 Y 16至 Y -63，最常见于 Y -58和-59附近（minecraft.wiki）。下列其他数值仅为近似，不同版本可能略有变化。

矿石最常见高度（约）用途
煤约 Y 96燃料与火把
铁约 Y 16以及山地工具、盔甲、桶

提示

挖矿时通过 F3（Java）或坐标设置（Bedrock）留意高度。挖钻石时，在 Y -58水平开隧道比随机探索高效得多。

Nether 与 End 之旅

#

Nether 是炽热的地下世界，其中一步约相当于主世界八步，传送门可缩短远途。Nether 门是竖直黑曜石框，最小4x5，角落可省，因此最少10块黑曜石。最大可达23x23（minecraft.wiki）。

  1. 1
    收集黑曜石

    向熔岩浇水生成黑曜石，用钻石镐采集10块。

  2. 2
    搭建并点燃传送门

    搭4格宽、5格高的框架，用打火石点燃内部。

  3. 3
    备齐物品进入 Nether

    带铁盔甲、剑、箭、不燃方块、水桶和充足食物。穿一件金盔甲能让猪灵不主动攻击你。

  4. 4
    寻找堡垒

    在 Nether 堡垒猎杀烈焰人获取烈焰棒，再加工成烈焰粉。

  5. 5
    收集末影珍珠

    猎杀末影人。末影珍珠加烈焰粉可合成末影之眼。

  6. 6
    找到要塞并进入 End

    投掷末影之眼，沿其飞行方向寻找地下要塞。将眼睛放入传送门框，跳入 End。

End 中有 Ender Dragon 及为它治疗的水晶。先用箭摧毁水晶，再近战巨龙。击败后出口传送门开启，折跃门通往外围岛屿，那里可找到末地城、Elytra 与潜影盒。

注意

不要在 Nether 的床上睡觉，床会爆炸。进入 End 时带大量方块用于架桥和掩护，并准备缓降手段；坠入虚空会丢失物品。

附魔、村民交易与农业基础

#

附魔台能永久增强物品。周围放15个书架，保持一格间隔，即可达到最高等级。附魔需要经验等级和青金石。

  1. 1
    收集经验与青金石

    通过采矿、冶炼和击杀生物获取经验，在地下开采青金石。

  2. 2
    摆放书架

    在附魔台周围环形摆书架，每个书架都会改善附魔选项。

  3. 3
    选择物品并附魔

    放入武器、盔甲或镐，加入青金石，点击一个附魔选项。

  4. 4
    开启村民交易

    工作站方块可赋予村民职业，例如讲台对应图书管理员。有职业的村民会用物品兑换绿宝石。

  5. 5
    锁定好交易

    交易能提升村民等级并开启新交易。治愈僵尸村民可降低价格。

  • 小麦：用种子种植，临水生长快，可做面包与饲料。
  • 畜牧场：牛、羊和鸡使用合适饲料繁殖，稳定产出肉、羊毛和牛奶。
  • 村民交易：使用绿宝石购买带有经验修补等强力附魔的书，是较安全的途径。

提示

可在铁砧将附魔物品与书合并；经验修补利用经验修复物品。优先给镐附魔，不要无计划消耗附魔资源。

多人模式、Realms 与安全安装模组

#

与朋友游玩有三种方式：自建服务器、加入公共服务器，或使用 Mojang 托管的订阅服务器 Realms。下表为 Minecraft 官方页面的美元标价，土耳其价格在页面另列。

方案月费同时在线人数
Realms (Bedrock)US$3.99你和2位玩家
Realms Plus (Bedrock)US$7.99你和10位玩家
Realms (Java)US$7.99你和10位玩家

首个 Realms 账号可免费试用30天。Java Realms 仅供 Java 玩家，Bedrock Realms 支持全部 Bedrock 设备。Java 还可使用模组：会改变游戏的文件，只应从可信来源下载。

  1. 1
    安装官方启动器

    用 Minecraft Launcher 启动一次 Java，确认游戏能打开。

  2. 2
    选择模组加载器

    Fabric、NeoForge 和 Quilt 是知名开源加载器。查看模组页面，确认所需加载器及版本。

  3. 3
    从可信渠道下载模组

    仅使用 Modrinth、CurseForge 等知名模组站。模组文件应以 .jar 结尾；若是 .exe，请删除。

  4. 4
    放入 mods 文件夹

    将文件放入游戏的 mods 目录，在启动器选择加载器配置后运行。

  5. 5
    先备份

    模组世界若损坏，可用备份恢复原世界。

注意

不要相信冒充模组的 .exe、承诺免费 Minecoins 的网站，或索要游戏账号密码的链接。这些行为意在窃取账号和控制电脑。

新手常见错误

#
  • 不带火把进入洞穴。应始终携带火把和水桶。
  • 死亡后不回收物品。物品掉在死亡地点，一段时间后消失。记下坐标，迅速返回，并把贵重物品存箱。
  • 在熔岩湖旁贸然挖掘。水要放在手边。
  • 直接靠近苦力怕。远程攻击，听到嘶嘶声就后退。
  • 不备份便更新世界，或用作弊破坏世界。

注意

死亡后物品掉落，很快会消失。立即记下死亡坐标，沿最短路线返回。

账号安全与家长控制

#

Minecraft 现使用 Microsoft 账号。儿童账号可通过 Microsoft 家庭设置限制聊天、多人游戏和购买。菜单名称可能变化，请亲自在账号网页核对。

  • 儿童宜使用熟人组成的封闭服务器或 Realms；公开服务器存在聊天风险。
  • 模组与材质包仅从 CurseForge、Modrinth 等知名大站下载。.exe 模组文件可能是恶意软件。
  • 免费 Minecoins 或免费账号网站是窃取登录信息的骗局。
  • 为 Microsoft 账号开启两步验证。

注意

不要信任买卖账号、Minecoins 或物品的网站。假下载与账号交易是账号丢失的常见原因。

常见问题

#
必须把 Java 和 Bedrock 一起买吗？

PC 上通常捆绑销售，两者都会获得；手机和主机只有 Bedrock。

可以单人玩吗？

可以。单人世界无需联网，服务器和 Realms 需要联网。

应该玩哪个版本？

通常选最新稳定版。若用模组，安装模组支持的版本。

怎样安装模组？

Java 先安装 Fabric 或 NeoForge 等加载器，再从 CurseForge 或 Modrinth 下载模组。Bedrock 使用 Marketplace 附加包。

不击败巨龙也能继续吗？

可以，这并非强制目标。Elytra 等物品位于 End，是否前往由你决定。

世界能转移到其他设备吗？

同一版本内可以导出、导入。Java 与 Bedrock 世界彼此不能直接兼容。
