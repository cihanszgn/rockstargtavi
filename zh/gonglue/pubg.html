游戏内容与2026年现状

#

PUBG: Battlegrounds 是大逃杀游戏，数十名玩家跳伞进入大地图，搜集武器、盔甲和物资，争取成为最后的生存者。比赛中安全区不断缩小，将所有人推向同一区域。游戏免费，PC 版可从 Epic Games Store 页面下载。

截至2026年11月，游戏为 44.1更新。官方补丁说明称本版带来 Rondo 的 IVE 联动、新活动模式及第44赛季排位奖励。PC 维护时间为11月4日，主机更新为11月12日。

官方概览说明每局最多100人，提供 Solo、Duo 和 Squad。空投 Care Packages 与地图载具是核心要素。想先练武器与移动，可去概览提及的训练区 Camp Jackal。

提示

本指南介绍长期有效的原则。武器平衡和地图轮换随更新变化，请查看官方补丁说明了解现状。

开始前：安装与配置

#

下列为官方配置要求。低于最低配置会卡顿；想流畅游玩，应尽量达到推荐配置。

  • 最低：64位 Windows 10、Core i5-4430 或 FX-6300、8 GB RAM、GeForce GTX 960 2 GB 或 Radeon R7 370、DirectX 11、40 GB可用空间。
  • 推荐：Core i5-6600K 或 Ryzen 5 1600、16 GB RAM、GeForce GTX 1060 3 GB 或 Radeon RX 580 4 GB、50 GB可用空间。
  • 账号：PC 可通过 Epic Games Store 页面安装，游戏免费。
  • 竞技配置：官方支持页另列 Core i9-9900K 或 Ryzen 7 3800X、32 GB RAM、GeForce RTX 2060 Super 或 Radeon RX 5700。
  • 跨平台：官方匹配说明称 PC 的 Steam 与 Epic 玩家互通，主机的 Xbox 与 PlayStation 玩家互通。PC 与主机同局尚无官方公告。
  • 主机：根据官方服务通知，自2025年11月13日起，PUBG Console 仅支持 PlayStation 5 和 Xbox Series X|S。
  • 土耳其语：Steam 列出土耳其语界面，Epic 列出该语言，PUBG Mobile 语言表也包含土耳其语。

提示

更新需要额外空间。空闲容量应略高于推荐值，避免每次补丁都要清理文件。

首批对局：分步开始

#
  1. A1
    先玩非排位

    起初避开 Ranked。普通对局失误不影响段位，可以熟悉地图与枪械手感。

  2. A2
    远离人群降落

    查看航线，选择远离大型聚落、靠近航线边缘的位置。众人常跳同一片大楼，几秒就死学不到什么。

  3. A3
    最初两分钟配齐装备

    拾取武器、弹药、盔甲、头盔与治疗物品。别执着找完美武器，能用现有装备战斗更重要。

  4. A4
    跟踪安全区

    经常开地图，提早前往下个圈。圈外会持续掉血，最后时刻赶路容易被追击。

  5. A5
    复盘死亡

    每局问三件事：枪从哪来、为何暴露、能否避战？简短复盘也能改善下局。

提示

前十局先追求存活时长，而不是击杀数。活得更久，击杀会自然增加。

降落、安全区与载具

#

开局五分钟的三个决定常影响整局：降落位置、读圈方式和何时用车。以下长期原则来自一般游戏经验，地图和载具清单请查官方页面。

  1. A1
    选择落点

    在航线边缘选密度适中、至少两栋建筑、附近有车的位置。太空旷可能没枪，太拥挤容易早死。

  2. A2
    判断首圈

    安全区出现后对照自身位置。靠中心可等待，距离远则及早找车。

  3. A3
    贴近圈边

    直冲中心会四面受敌。圈边通常背后较安全，只需重点观察一个方向。

  4. A4
    有目的地用车

    载具移动快，但声音传得远，会让你成为显眼目标。用于长距离赶路，别直接开进近战；先停车找掩体。

提示

官方地图页列出各图特色载具与设施，例如 Erangel 的 Erangel Ferry 和 UAZ。各图有哪些车型，请查地图页和官方载具页。

#

官方武器页按 AR、DMR、SMG、SR、霰弹枪、手枪、近战、投掷物等分类。下表按此分类并结合一般游戏知识。官方没有弹药表，选枪时以游戏内说明为准。

提示

武器平衡随更新变化。关注类别定位，而非最强武器榜，选择适合手中装备的战斗。

核心机制

#

游戏依赖少数原则。掌握后，不管当前哪把枪强，你都有良好基础。

  • 位置与高度：高处掩体有优势，站在空地最容易被击中。
  • 声音：脚步、枪声和车辆会暴露敌人位置。好耳机是成本最低的改善。
  • 盔甲与头盔：等级越高，吸收伤害越多。危险交火前备好治疗物品。
  • 安全区管理：早走、用车安全穿越、在圈边选位，胜过晚到被追赶。
  • 团队协作：用标记给简短清楚的信息。抛弃倒地队友往往让两人都输。

提示

每次开战前规划退路：退到哪、谁掩护？没有计划的战斗就是赌博。

设置：稳妥的起点

#

这些只是起点，应依硬件和习惯调整。每次只改一项，试几局再决定。

  • 帧率限制：设为显示器刷新率，更高只会增加发热。
  • 画质预设：先选中等，降低阴影与特效，按显存选择纹理质量。
  • 分辨率：保持显示器原生分辨率，模糊会妨碍发现目标。
  • 灵敏度：从中间值开始，每次调整百分之五至十。天天更改会破坏肌肉记忆。
  • 音频：用耳机，调低音乐和环境音，让脚步更突出。

提示

帧率差时先降阴影，再降特效，最后降分辨率。这种顺序损失的画质最少。

新手常见错误

#
  • 逢战必接。追着每声枪响跑，会成为第三方目标。先看位置。
  • 圈外拖延。只搜物资不看圈，会掉血并陷入慌乱。
  • 空地治疗。用药时易受攻击，先躲墙后或树后。
  • 忽视噪声。跑步和车辆声会暴露自己，接近目标时慢下来。
  • 不断改设置。每局都换灵敏度会妨碍进步。
  • 抛下队伍。组队时一起移动、分享情报。

提示

总在同一位置死亡就换落点。新手每局从不同且安静的地方起步，往往进步最快。

账号安全与消费提醒

#

游戏虽免费，外观、活动通行证和箱子可付费购买。决定前看清购买界面，区分随机与固定内容。

  • 设定每月预算并遵守，不保存支付方式。
  • 开启两步验证，不与其他网站共用密码。不要相信游戏外免费皮肤或免费 UC 承诺。只在官方游戏及商店界面输入账号，点击可疑链接前核对地址。
  • 为儿童在商店或主机设置家长控制，消费需经批准。
  • 不要相信假免费皮肤链接或索要登录的网站，密码只填官方登录页。

注意

远离作弊软件、自瞄、宏、账号买卖及代练。官方定期公布封禁，这些做法可能永久丢号，也常是骗局。

常见问题

#
PUBG 免费吗？

是的，无需消费；购买内容主要是外观。

PC 配置够吗？

最低为64位 Windows 10、8 GB RAM 及 GTX 960级显卡。要流畅游玩，应达到推荐配置。

先玩哪张地图？

没有强制顺序，先玩轮换分配的地图；Erangel 是经典入门图。

何时进排位？

普通局能从容处理安全区、物资和基本交火后再进，不必着急。

PUBG Mobile 是同一款游戏吗？

同系列的独立应用，操作、模式及更新时间表不同。

PC 和主机玩家互通吗？

官方匹配说明称 PC 的 Steam 与 Epic 互通，主机的 Xbox 与 PlayStation 互通。PC 与主机同局尚未正式公布。

遇到作弊者怎么办？

使用游戏内举报并保存证据，不要自行报复；你若使用禁用软件，同样会被封。
