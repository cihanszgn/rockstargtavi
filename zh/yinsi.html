隐私政策

最后更新：2026年11月15日

本站无需注册账号，也不收集姓名、邮箱等个人信息。

托管

本站托管于 GitHub Pages。GitHub 可能出于安全目的记录访问者 IP，详情见GitHub 隐私声明。

分析与广告

我们使用 Google Analytics 了解访问人数及阅读页面。Google Analytics 通过 Cookie 收集浏览器类型、设备、大致位置（城市／国家）、来源网站、页面停留时间等匿名统计。我们不以此识别个人，仅用于了解哪些内容对读者有用。

数据处理方式见 Google 合作网站说明。如需阻止追踪，可禁用浏览器 Cookie，或安装 Google Analytics 停用浏览器插件。

本站目前没有广告。如未来加入广告，本页会更新。

浏览器本地存储

主题（浅色／深色）、新闻视图（网格／列表）、要闻暂停偏好及关注游戏列表仅保留在你的浏览器 localStorage 中。语言建议的选择与关闭状态也保存在此。这些信息不会发送给我们或其他服务器，清除本站浏览器数据即可移除。

优惠与免费游戏数据

相关页面直接由浏览器向 CheapShark 请求实时价格，商店图标也来自 cheapshark.com。游戏缩略图来自 Steam、Epic Games Store 等商店服务器。请求不包含你当前浏览的页面，但这些服务与其他网站服务器一样可看到 IP 与浏览器类型。优惠链接经 CheapShark 前往商店，本站不收佣金。

新闻图片

新闻卡片和文章中的图片直接从 Xbox Wire、PlayStation Blog 等官方来源服务器加载，本站不复制图片。请求不包含当前页面，但来源服务器能看到 IP 与浏览器类型。图片加载失败时显示本站生成的封面。
