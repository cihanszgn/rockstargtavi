Politique de confidentialité

Dernière mise à jour : 15 novembre 2026

Ce site ne demande pas de compte et ne collecte aucune donnée personnelle, comme votre nom ou votre adresse e-mail.

Hébergement

Le site est hébergé sur GitHub Pages. Pour des raisons de sécurité, GitHub peut enregistrer l'adresse IP des visiteurs. Détails : Déclaration de confidentialité de GitHub.

Statistiques et publicité

Nous utilisons Google Analytics pour savoir combien de personnes visitent le site et quelles pages sont lues. Via des cookies, Google Analytics collecte des statistiques anonymes : type de navigateur, appareil, localisation approximative (ville/pays), site d'origine et temps passé sur la page. Nous ne vous identifions pas personnellement avec ces données ; nous les utilisons uniquement pour comprendre quels contenus sont utiles.

Comment Google traite les données : sites partenaires de Google. Pour empêcher le suivi, vous pouvez désactiver les cookies dans votre navigateur ou utiliser le module complémentaire de navigateur pour la désactivation de Google Analytics.

Il n'y a actuellement aucune publicité sur le site. Si des publicités sont ajoutées à l'avenir, cette page sera mise à jour.

Ce qui est enregistré dans votre navigateur

Votre choix de thème (clair ou sombre), l'affichage des actualités (grille ou liste), la préférence de pause du fil d'actualité et la liste des jeux que vous suivez sont conservés uniquement dans votre navigateur, dans localStorage. Ces informations ne nous sont jamais envoyées, ni à aucun autre serveur ; vous pouvez les supprimer en effaçant les données de ce site dans votre navigateur.

Données des promos et des jeux gratuits

Les pages Promos et Jeux gratuits obtiennent les prix du moment en envoyant des requêtes depuis votre navigateur directement à CheapShark ; les icônes des boutiques sont aussi chargées depuis cheapshark.com. Les vignettes des jeux proviennent des serveurs des boutiques (par exemple Steam ou l'Epic Games Store). Ces requêtes n'indiquent pas la page que vous consultez, mais comme tout serveur web, ces services peuvent voir votre adresse IP et votre type de navigateur. Les liens des promos mènent à la boutique via CheapShark ; ce site ne touche aucune commission.

Images des actus

Les images des actus sont chargées depuis le serveur de la source : la photo affichée sur les cartes et les pages d'actu arrive dans votre navigateur directement depuis le serveur de la source officielle de l'info (par exemple Xbox Wire ou le PlayStation Blog) ; ce site ne copie pas les images. Ces requêtes n'indiquent pas la page que vous consultez, mais ce serveur peut lui aussi voir votre adresse IP et votre type de navigateur. Si une image ne peut pas être chargée, une couverture générée par ce site s'affiche à la place.

Liens externes

Les sites externes que nous citons comme sources appliquent leurs propres règles de confidentialité.
