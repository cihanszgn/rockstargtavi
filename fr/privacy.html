Politique de confidentialité

Dernière mise à jour : 9 novembre 2026

Ce site ne demande pas de compte et ne collecte aucune donnée personnelle, comme votre nom ou votre adresse e-mail.

Hébergement

Le site est hébergé sur GitHub Pages. Pour des raisons de sécurité, GitHub peut enregistrer l'adresse IP des visiteurs. Détails : Déclaration de confidentialité de GitHub.

Statistiques et publicité

Nous utilisons Google Analytics pour savoir combien de personnes visitent le site et quelles pages sont lues. Via des cookies, Google Analytics collecte des statistiques anonymes : type de navigateur, appareil, localisation approximative (ville/pays), site d'origine et temps passé sur la page. Nous ne vous identifions pas personnellement avec ces données ; nous les utilisons uniquement pour comprendre quels contenus sont utiles.

Comment Google traite les données : sites partenaires de Google. Pour empêcher le suivi, vous pouvez désactiver les cookies dans votre navigateur ou utiliser le module complémentaire de navigateur pour la désactivation de Google Analytics.

Il n'y a actuellement aucune publicité sur le site. Si des publicités sont ajoutées à l'avenir, cette page sera mise à jour.

Liens externes

Les sites externes que nous citons comme sources appliquent leurs propres règles de confidentialité.

Ce site est un site de fans indépendant. Il n'a aucun lien avec Rockstar Games ni Take-Two Interactive.
